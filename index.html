A few quick answers

Good to know.

New here? These are the basics.

What can I create with Project?

Use Presentr for presentations, Siteify for websites, Formr for forms and Cloudbase for file storage.

Can I publish a website?

Yes. The website builder supports publishing to an Project address, with custom-domain setup for domains you own.

Is Project free?

Yes. The workspace is designed to be free to use, with no subscription tiers.

Can I present to an audience?

Yes. Presentations include separate presenter and audience experiences.
